## Website Architecture & Technology Stack

### Frontend Technology
- **Framework:** React with TypeScript (mobile-first design)
- **Styling:** Tailwind CSS with custom theme configuration
- **Routing:** Wouter (lightweight client-side routing)
- **UI Components:** Radix UI + Shadcn UI (accessibility-compliant)
- **State Management:** React Query for data fetching
- **Build System:** Vite (optimized for performance)

### Backend Technology
- **Server:** Node.js with Express.js
- **Database:** PostgreSQL (Neon cloud-hosted)
- **ORM:** Drizzle (type-safe database operations)
- **AI Integration:** Multi-provider (OpenAI GPT-4o, Google Gemini 2.0 Flash)

### SEO Infrastructure
- **Structured Data:** Complete Schema.org implementation
- **Meta Tags:** Comprehensive Open Graph and Twitter Cards
- **Sitemap:** Auto-generated XML sitemap covering all key pages
- **Robots.txt:** Properly configured for search engine crawling
- **Mobile-First:** Responsive design optimized for mobile ranking
- **Performance:** Optimized loading with lazy loading and code splitting
