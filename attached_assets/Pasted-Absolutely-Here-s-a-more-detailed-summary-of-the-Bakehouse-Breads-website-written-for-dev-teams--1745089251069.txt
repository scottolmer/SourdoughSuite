Bakehouse Breads – Full Website Summary for Development

Project Overview

Bakehouse Breads is a warm, premium sourdough baking platform combining ecommerce, educational content, and AI-powered interactive tools. The site is designed to support both beginners and advanced bakers by offering:
	•	A curated shop of specialty sourdough starters
	•	Custom-built tools like a Recipe Validator and Baking Timeline Generator
	•	A conversational AI assistant to guide users across all areas
	•	Educational elements that build user confidence and deepen their baking knowledge

It blends artisan aesthetics with modern UX/UI, and aims to become the go-to digital ecosystem for sourdough enthusiasts.

⸻

Core Pages & Functional Modules

1. Homepage
	•	Hero Banner: A bold headline (“Your Authority in Specialty Sourdough”), subheadline, and chat CTA button (“Ask the Bread Assistant”)
	•	Featured Starters: Grid of top-selling starter products, each with image, price, badge (e.g., “Bestseller”), and quick summary
	•	Interactive Tools: Two-card preview of Validator + Timeline, each linking to tool page
	•	Newsletter Sign-Up: Full-width block with email input and subscribe button
	•	Floating Chat Bubble: Persistent chat launcher in lower right corner

2. Shop (Starters)
	•	Starter Catalog: Filterable grid of all starter types (Koji, SF, Kombucha, Hybrid)
	•	Individual Product Page:
	•	Image gallery
	•	Description
	•	Price
	•	Add-to-cart
	•	Flavor profile graph
	•	Maintenance needs
	•	Ideal usage styles (e.g., “Best for enriched doughs”)

3. Tools Page
	•	List of Tools:
	•	Recipe Validator: Users input recipe details and receive instant hydration %, salt %, starter ratio, and professional feedback
	•	Baking Timeline Calculator: Users choose a bread, starter, environment, and end time — the tool generates a full schedule with active and passive time, temperature, and reminder setup
	•	Starter Health Check (Future): Tool for visually assessing starter health
	•	Feeding Schedule Generator (Future): Creates personalized starter care calendars

⸻

Key Components and Reusable UI

Chat System
	•	ChatBubble: Floating button to toggle open/close
	•	ChatPanel: Right-side drawer panel with sliding animation
	•	MessageList, MessageBubble, SuggestedQuestions, ChatInput: Core chat UI with bot typing animation and multi-agent handling (e.g., validator agent, starter expert)

Product Components
	•	ProductCard, ProductGallery, AddToCart, ProductTabs: Modular ecommerce components
	•	Designed for future use with WooCommerce, Shopify Headless, or custom cart system

Interactive Tool Components
	•	RecipeForm, TimelineGenerator, AnalysisResults, TimelinePeriod
	•	Timeline blocks visually adjustable with real-time schedule regeneration
	•	Validator displays dough metrics, improvement tips, starter-specific guidance

⸻

Technology Stack

Frontend
	•	React (Create React App or Vite)
	•	Tailwind CSS (Custom theme w/ serif + sans-serif typography)
	•	Lucide-React (Icon system)
	•	React Router DOM

Backend/API
	•	LLM-based responses from OpenAI (or HuggingFace-compatible backend) for chat tools
	•	Timeline + Validator logic run client-side or via simple Node.js API routes

Hosting Platform
	•	Replit-compatible; can also deploy to Vercel, Netlify, or WordPress (with some adaptations)

⸻

Design Language

Color Palette
	•	Primary: #A0522D (Sienna) – buttons, accents
	•	Secondary: #F5F5DC (Beige) – backgrounds, cards
	•	Highlight: #B8860B (Goldenrod) – interactive elements
	•	Text: #4A2A1A (Dark Brown) – body text
	•	Optional Accent: #8FBC8F (Natural Green) – for freshness cues or health indicators

Typography
	•	Headings: Merriweather or Lora (Serif)
	•	Body: Inter, Lato, or Open Sans (Sans-serif)
	•	Consistent pairing across screens with font scaling for responsiveness

Imagery Style
	•	Natural lighting, close-up bread textures, clean compositions
	•	Consistent rustic-modern aesthetic
	•	Placeholder used in dev phase for all product thumbnails

⸻

Special Features

1. Chat-First Navigation
	•	AI assistant can guide users to products, tools, and educational content
	•	Different agents answer recipe, fermentation, shopping, or scheduling questions

2. Validator & Timeline Tools
	•	Tools build trust and confidence through feedback
	•	Formulas and schedules adapt based on starter type, temperature, and user availability

3. Accessibility
	•	Contrast-checked color scheme
	•	Large clickable targets on mobile
	•	Semantic HTML and ARIA compliance for major elements
