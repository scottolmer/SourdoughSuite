# Detailed Timeline Calculator Screen Specifications

## 1. Entry Dashboard (Home Screen)

### Top Section
- **Header Bar**
  - Left: Bakehouse Breads logo in charcoal/amber
  - Center: "Timeline Calculator" in serif typography
  - Right: User account icon/menu and notification bell

- **Welcome Module**
  - Personalized greeting based on time of day and user name
  - Context-aware suggestion (e.g., "Perfect time to plan your weekend bake")
  - Current date and time display (important reference point)
  - Quick action button: "+ New Timeline"

### Timeline Gallery
- **Layout**: Horizontal scrolling cards, 3 visible at once on desktop
- **Card Structure**:
  - Top: Recipe thumbnail and name
  - Middle: Target completion time/date with countdown
  - Bottom: Progress bar showing timeline completion
  - Status indicator (Scheduled, In Progress, Completed)
  - Tag for starter type used (small colored pill)
  
- **Card States**:
  - Active: Currently in progress (highlighted border)
  - Scheduled: Upcoming (standard appearance)
  - Completed: Finished (subtle grayscale treatment)
  - "Create New" card at end of list (dashed border with + icon)

### Quick Start Section
- **Template Selector**
  - Section title: "Quick Start with Templates"
  - Layout: Grid of 6 template cards showing common bread types
  - Each card shows: Image, name, total duration, difficulty

- **Recent Activity**
  - Section title: "Continue Where You Left Off"
  - Timeline drafts not yet completed
  - Recently viewed timelines
  - Option to continue from Recipe Validator

### Bottom Navigation
- Primary action button: "+ Create Timeline" (amber)
- Secondary navigation:
  - "My Timelines" (saved/completed)
  - "Calendar View" (weekly schedule)
  - "Settings" (preferences)

## 2. Goal Definition Screen

### Header Section

### Special Options Panel

- **Flexibility Settings**:
  - "Exact Time" vs "Time Window" toggle

    - Range selector for acceptable completion period

  - Optional advanced view with precise humidity input

- **Visual Temperature Impact**:
  - Graph showing relationship between temperature and fermentation
  - Highlighted "ideal zone" for selected recipe
  - Current selection marker on curve
  - Estimated impact on total fermentation time

### Starter Details Panel

### Equipment Capabilities Panel

- **Refrigeration Options**:
  - Refrigerator temperature input
