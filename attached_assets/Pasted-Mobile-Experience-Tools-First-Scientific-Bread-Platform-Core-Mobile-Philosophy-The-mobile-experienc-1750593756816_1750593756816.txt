Mobile Experience: Tools-First Scientific Bread Platform
Core Mobile Philosophy
The mobile experience prioritizes immediate practical value over deep research, recognizing that mobile users often need quick answers and calculations while actively baking.

Mobile Navigation & Layout
Home Screen
Top Navigation: Clean header with search bar and menu toggle
Quick Tools Section: Prominent cards for the 4 core calculators
Topic Cards Grid: Visual topic browsing with article counts and brief descriptions
Search Integration: Persistent search bar with voice input capability
Recent/Suggested: Personalized recommendations based on usage
Responsive Grid Layout
Portrait: Single column with stacked tool cards
Landscape: Two-column layout for efficient browsing
Touch-Optimized: Large tap targets, swipe gestures, pull-to-refresh

Mobile User Journey Examples
Scenario 1: Active Baker
7 AM: User opens app while making coffee
Timeline Tool: Checks fermentation schedule, sets reminder
Notification: "Shape your dough now" at 6 PM
Quick Chat: "Is my dough ready?" with photo
AI Response: Analysis + next steps
Scenario 2: Learning Baker
Research Mode: Browses "Beginner Sourdough" topic card
Article Preview: Reads condensed version of starter science
Tool Discovery: "Try the hydration calculator" suggestion
Recipe Creation: Uses ratios calculator for first loaf
Timeline Setup: Plans weekend baking schedule
Scenario 3: Problem Solving
Issue: Dense loaf, frustrated baker
Troubleshooter: Selects "dense/heavy" + answers questions
Diagnosis: Under-fermented + too much flour
Solutions: Specific adjustments + research citations
Prevention: Saves timeline for future bakes
