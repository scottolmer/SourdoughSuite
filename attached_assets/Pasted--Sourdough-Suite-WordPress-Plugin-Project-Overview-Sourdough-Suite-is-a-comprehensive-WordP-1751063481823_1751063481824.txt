# Sourdough Suite WordPress Plugin

## Project Overview
**Sourdough Suite** is a comprehensive WordPress plugin for sourdough baking education featuring scientific article integration, recipe enhancement, and research-backed insights. The system uses admin-only uploads for research summaries, automatically links scientific insights to recipes, and enhances public recipe displays with "Why This Works" sections backed by peer-reviewed research.

## Current Status: Architecture Complete, Ready for WordPress Testing Environment

## Project Architecture

### Core System Design
- **WordPress-native frontend approach** for maximum theme compatibility
- **Admin-only upload system** eliminates multi-user complexity and maintains quality control
- **Hybrid processing strategy** (sync for small files <5MB, queue for larger files) with real-time progress tracking
- **Intelligent recipe auto-linking algorithm** using content analysis and confidence scoring
- **Mobile-first responsive design** with conditional asset loading

### Database Schema (7 Tables)
1. `sourdough_article_summaries` - Core research data storage
2. `sourdough_research_insights` - Extracted actionable insights  
3. `sourdough_recipe_research_links` - Recipe-research connections
4. `sourdough_processing_queue` - File processing management
5. `sourdough_analytics` - User interaction tracking
6. `sourdough_temp_files` - Temporary file management
7. `sourdough_settings` - Plugin configuration

### Technical Implementation
- **Language:** PHP 7.4+ with WordPress 5.0+ compatibility
- **Frontend:** jQuery + CSS (WordPress-native approach)
- **File Processing:** Multi-format support (PDF, Word, Text, JSON)
- **Security:** Advanced file validation, nonce verification, resource monitoring
- **Performance:** Optimized database queries, conditional asset loading

## Implementation Decisions Made
- **File Processing:** Hybrid approach (sync <5MB, async >5MB)
- **Recipe Detection:** Aggressive auto-detection with manual override capability
- **Confidence Algorithm:** Weighted scoring (hydration 30%, fermentation 25%, technique 20%, etc.)
- **Mobile Priority:** Mobile-first responsive design approach
- **Analytics Scope:** Basic privacy-friendly interaction tracking
- **Permission Model:** Admin-only for V1, expandable for V2
- **Asset Loading:** Conditional loading only when needed
