## 9. Visual Design System

### Color Palette
- **Primary**: Amber (#D97706) for actions and highlights
- **Secondary**: Deep charcoal (#1C1917) for text and accents
- **Background**: Warm white (#FFFBF5) for main surfaces
- **Supporting Colors**:
  - Light gray (#F9FAFB) for inactive states
  - Medium gray (#E5E7EB) for borders and dividers
  - Dark amber (#B45309) for hover states

### Typography
- **Primary Font**: Serif typeface for headings and product names
  - Weights: Regular (400), Medium (500), Semibold (600)
  - Sizes: 32px (main headers), 24px (section headers), 20px (card titles)

- **Secondary Font**: Sans-serif for body text and UI elements
  - Weights: Regular (400), Medium (500)
  - Sizes: 16px (body), 14px (secondary text), 12px (captions)

### UI Components
- **Cards**:
  - Subtle shadow (0px 4px 6px rgba(0, 0, 0, 0.05))
  - 8px border radius
  - 16px internal padding
  - Optional subtle grain texture

- **Buttons**:
  - Primary: Amber background, white text, 4px radius
  - Secondary: White background, amber border, amber text
  - Tertiary: No background, amber text, subtle underline on hover
  - States: Default, Hover, Active, Disabled

- **Selection Elements**:
  - Radio buttons: Custom design with amber active state
  - Checkboxes: Square with rounded corners, amber check
  - Sliders: Custom handle with amber track for active portion
  - Toggle switches: Amber background when active

- **Iconography**:
  - Consistent line weight (1.5px)
  - Rounded corners and cap style
  - Monochrome with amber accent for active states
  - Simple, clear shapes with good touch targets

## 11. Accessibility Considerations

### Purpose
Ensure the quiz is usable and enjoyable for all users regardless of abilities.

### Key Features
- **Keyboard Navigation**
  - Full functionality without mouse
  - Logical tab order through all interactive elements
  - Clear focus states for all interactive components
  - Keyboard shortcuts for primary actions

- **Screen Reader Support**
  - Semantic HTML structure
  - ARIA labels for all interactive elements
  - Meaningful alt text for all images
  - Announcements for dynamic content changes

- **Visual Accessibility**
  - Color not used as the only means of conveying information
  - High contrast mode option
  - Text resizing without breaking layouts
  - Sufficient color contrast ratios (WCAG AA compliance)

- **Cognitive Accessibility**
  - Clear, simple language
  - Consistent placement of navigation elements
  - Progress indicators throughout
  - Option to review all answers before submission
