6. Add to Cart Button Logic

You’ll likely use a cart context or global state:

import { useCart } from "../context/CartContext";

export default function AddToCartButton({ product }) {
  const { addItem } = useCart();

  return (
    <button
      onClick={() => addItem(product)}
      className="mt-2 bg-amber-600 text-white px-4 py-2 rounded hover:bg-amber-700"
    >
      Add to Cart
    </button>
  );
}

7. Cart Context (Basic Version)

import { createContext, useContext, useState } from "react";

const CartContext = createContext();

export function CartProvider({ children }) {
  const [items, setItems] = useState([]);

  const addItem = (product) => {
    setItems((prev) => [...prev, product]);
  };

  return (
    <CartContext.Provider value={{ items, addItem }}>
      {children}
    </CartContext.Provider>
  );
}

export function useCart() {
  return useContext(CartContext);
}

8. Sort Dropdown

export default function SortDropdown({ onChange }) {
  return (
    <select
      onChange={e => onChange(e.target.value)}
      className="border px-3 py-2 rounded"
    >
      <option value="popularity">Sort by: Popularity</option>
      <option value="price-low-high">Price: Low to High</option>
      <option value="price-high-low">Price: High to Low</option>
    </select>
  );
}

9. Backend Integration Tips

You can fetch product data from:
	•	WordPress REST API via wp-json/wp/v2/products
	•	Shopify Buy SDK or custom Shopify Storefront API
	•	Sanity, Strapi, or Contentful with filters/tags

Use getStaticProps or getServerSideProps (Next.js) or fetch on mount (useEffect) depending on your SSR/CSR setup.

10. Checkout Integration Options

	•	Shopify Buy SDK: Add-to-cart and checkout using Shopify’s backend
	•	Snipcart / Foxy.io: Drop-in cart + checkout tools
